# EpochPact 0.1.2-dev.29

Better Turkish and Russian texts, and clearer auto pickup descriptions.

## Auto pickup texts

- **Auto pickup** now says what decides what is collected: your **Pickup mode**
  and **Pickup category** choices.
- **Auto pickup interval** and **Auto pickup radius** are clearer: longer
  intervals reduce system load; at radius 0 every drop the game has loaded in
  your current area is collected.
- Thanks to a Russian player for the suggestions.

## Türkçe and Русский

- Units and decimals as in each language: "0,25–10 sn" / "0,25–10 с" instead
  of "0.25–10 s".
- Russian uses one word for auto pickup (автоподбор) everywhere.
- A full review of both translations corrected about 70 texts: wrong meanings,
  grammar, quotation marks and consistent terms.

## Updating

With 0.1.2-dev.22 or later: **New version · What's new → Install update** in
the app. From an older version: close Last Epoch and EpochPact, extract the
**complete new ZIP**, open `EpochPact/EpochPact.exe`, and select **Game setup →
Reinstall / update mod**.

Tests: [translation review](https://github.com/falorfrozen-cmd/EpochPact/blob/v0.1.2-dev.29/docs/translation-review-2026-10-14.md).
