EpochPact brings Last Epoch's offline tools together in one English desktop app,
with the Chronoforge and Void Atlas themes.

- Progression and combat: XP, gold, drop quantity, rarity, monster density, movement speed and cooldowns.
- Character bonuses: search, edit and reset the 206 character-sheet mappings.
- Loot and crafting: smart pickup, filter/LP/T7 options, forge tuning and material preservation.
- Campaign, waypoints, Monolith timelines, Corruption, Stability and Circle of Fortune controls.
- Unique Atlas, Stash Assistant and existing Echo reward navigation.

Game setup remembers your selected Last Epoch.exe, supports Steam and custom
folders, and installs the player mod only when you press Install mod. Save-changing
actions use their own buttons and backups. Weaver and Merchant's Guild management
remain informational.

Closing EpochPact now finishes accepted jobs and resets this session's temporary
settings and owned character bonuses. Saved progress and rewards remain. Native
shutdown protection cancels queued work and stops the command worker before the
runtime is destroyed.

Download **EpochPact-Windows-x64.zip**, extract it and open **EpochPact.exe**.
The separate EXE is the same build. Select Last Epoch.exe, close the game, install
the mod, then launch offline. Python is bundled. Windows 10/11 x64, WebView2
Runtime and .NET Framework 4.8 are required. Target: Last Epoch **1.5.2**, offline only.

Validation: 137 Python tests, 74 JavaScript tests, all ten native test programs
and 14 compiled-package checks passed. The package checks exercise installation
and the real HTTP interface in isolated fixtures; they do not retest every
gameplay feature. SHA256SUMS and build-info.json identify the uploaded artifacts.

This is an **alpha**. Closing the desktop panel was live-verified separately.
A UnityPlayer crash on full game exit was also observed with EpochPact completely
removed. The final native shutdown changes passed the synthetic lifecycle harness,
but a clean live game shutdown is not yet verified. See the source documentation
for the detailed shutdown and gameplay coverage; this release does not claim zero crashes.
