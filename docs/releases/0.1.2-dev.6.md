# EpochPact 0.1.2-dev.6 — Latest Changes

Windows x64 desktop package for offline Last Epoch. Live verification used Steam
Last Epoch 1.5.2.1, build 25816319 (internal version 1.5.2.2). This is a development
build with the limitations listed below, not a guarantee for other game versions.

## Bug fixes and usability

- Auto-pickup pauses while you inspect an item and resumes after its tooltip closes.
- Improved installation permission handling, administrator installation and rollback.
- Startup avoids blank/old interfaces and never reuses an unrelated older UI server.
- Refreshed connection, character and area state avoids stale disabled Apply buttons.
- Corruption, Stability and other draft values survive Alt-Tab and refresh.
- Corrected stat bonus application, percentage conversion and live bonus readings.
- Choose Mastery opens the game's first-choice panel for eligible characters who
  completed the campaign but missed mastery selection. It does not respec an existing mastery.
- Player-facing results use readable messages instead of raw diagnostic JSON.
- Corrected projectile double-multiplication, mixed crafting serialization limits,
  recipe collisions and crafting-material backup restoration.
- Crafting has its own menu. Direct General setting edits apply automatically;
  save-changing actions still require their dedicated buttons.

## New features

- Skill XP multiplier, separate from character XP.
- Passive point multiplier, including fractional values such as 1.5x.
- Skill point multiplier, including skill levels granted by equipment.
- Skill, Passive and Weaver tree connection bypasses. Point budgets and node caps remain.
- Weaver point multiplier and flat extra points.
- Offhand restriction bypass and full set bonuses from one equipped set piece.
- Maximum blessing rolls and 3, 4 or 5 blessing choices for new rewards.
- Camera zoom and angle controls; shadows, reflections, fog, bloom, ambient occlusion
  and motion blur controls where the corresponding game effect exists.
- Summon stat editing, live summon stats and duration adjustments. Expanded lifetime
  support includes Wraiths, Totems and Ballistas.
- Projectile multiplier and flat extra projectiles. Beams and stationary areas are excluded.
- Custom Crafting Workshop: mix up to 64 individual Unique/Set modifier lines plus
  six regular T7 affixes and an optional whole Unique/Set template. Scripted item
  mechanics outside those modifier lines are not transferred.
- Stock crafting materials to a chosen amount, up to 1,000,000. This tops up existing
  storage; it does not continuously generate an infinite supply or reduce larger stocks.
- Adjustable auto-pickup radius, nearby chest opening, shrine activation and one-use
  automatic portal interaction.
- Inventory shortcuts: Stash, Stash All and Vendor.
- Optional MelonLoader compatibility bridge, tested with MelonLoader 0.7.3.

## Installation and persistence

Extract the entire ZIP and keep `EpochPact.exe` beside its `_internal` folder.
Run the EXE, choose `Last Epoch.exe` in Game setup, install with the game closed,
then launch offline. Python is bundled; Windows 10/11 x64, WebView2 Runtime and
.NET Framework 4.8 are required. MelonLoader is optional and is not bundled.

Mixed custom items require EpochPact and `<game>/EpochPact/workshop-recipes.txt` on
each machine. Keep that recipe database with your saves. Restore original gear
before uninstalling, and do not overwrite another independent recipe database.
These items and session point multipliers are not promised to work mod-free on
Steam Deck through Steam Cloud. Ordinary material quantities use normal game saves.

## Verification and known limitations

The final validation recorded 63 frontend tests, 64 Python bridge/crafting/Melon
tests, 14 native test executables and 20 compiled-package checks. Actual final-player
EXE crafting, projectile settings, summon lifetime paths and native item persistence
were also exercised. The final normal game exit returned 0x00000000; original saves
and runtime files were restored. A successful build is not an exhaustive gameplay test.

- Not every skill variant or all 2,498 individual modifier lines were live-tested.
  Abomination channel-duration support still needs live verification.
- An intermittent UnityPlayer character-loading crash in a MelonLoader session
  remains under investigation. Compatibility with every third-party mod is not guaranteed.
- No fresh VirusTotal or Nexus scan has been performed for this build. Older alpha.5
  scan results do not apply to these new binaries.
