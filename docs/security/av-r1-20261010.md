## What changed

1. **VERSIONINFO on all three binaries.** `native/version_info.h` holds the shared
   values; `native/proxy/version.rc` and `native/core/core.rc` are compiled by
   `native/build.bat`; `tools/build_player.py` writes the same fields for the EXE
   (`EPOCHPACT_VERSION_FILE`, read by `EpochPact.spec`). The loader identifies
   EpochPact, never Microsoft. Bump `EP_VERSION_*` with each release.
2. **PyInstaller bootloader rebuilt from source.** The bootloader shipped in the
   PyPI wheel is byte-identical across every PyInstaller app, including malware,
   so engines learn its bytes. Same source, our compiler, different bytes.

## Reproducing the build (Windows x64, Python 3.13, MSVC)

```powershell
py -3.13 -m venv build\av-venv
build\av-venv\Scripts\python.exe -m pip install --require-hashes -r requirements-build-win64.lock
build\av-venv\Scripts\python.exe -m pip download pyinstaller==6.20.0 --no-binary :all: --no-deps -d build\av-src
# Verify: sha256 95c5c7e03d5d61e9dfb8ef259c699cf492bb1041beb6dbe83696608cec07347a (PyPI sdist)
tar -xzf build\av-src\pyinstaller-6.20.0.tar.gz -C build\av-src
Remove-Item build\av-src\pyinstaller-6.20.0\PyInstaller\bootloader\Windows-64bit-intel\*.exe
cd build\av-src\pyinstaller-6.20.0\bootloader
..\..\..\av-venv\Scripts\python.exe waf all --target-arch=64bit   # waf finds MSVC itself
cd ..\..\..\..
build\av-venv\Scripts\python.exe -m pip install --no-deps --force-reinstall build\av-src\pyinstaller-6.20.0

native\build.bat player
build\av-venv\Scripts\python.exe -m tools.build_player --layout onedir --version 0.1.1-alpha.5 --output dist/player/av-r1-20261010 --work build/player-av-r1 --stage build/player-resources-av-r1
build\av-venv\Scripts\python.exe -m tools.verify_player_package --exe dist/player/av-r1-20261010/EpochPact/EpochPact.exe --game-assembly "<local GameAssembly.dll>" --report build/av-r1-compiled-check.json
```

Built here: `runw.exe` sha256 `60d10ff93df9101ea52a31f2924f0ed873d115fff5a65417b79e226538f01718`
(official wheel: `1015b3391b8e45c2760d4f15f4089aa9cb043f8e56e4051e8234e0e3d2556c10`).
A rebuild on another machine/compiler produces different bytes and needs its own scan.
