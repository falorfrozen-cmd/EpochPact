# Discussion draft

**EpochPact — offline tools and build experiments for Last Epoch**

I've been building EpochPact, a community-made Windows app for Last Epoch's offline characters. It includes progression and loot tuning, character bonuses, crafting controls, campaign/Monolith tools and several quality-of-life options.

The latest update improves inventory shortcuts and nearby interaction performance, adds free tree respec, customizable navigation/stat displays and actual combat DPS for summoned allies.

Please read the supported build and known limitations before installing. This is a development release, not a guarantee of compatibility with every mod or PC. Online play is unsupported. Back up your offline saves.

Downloads and source: https://github.com/falorfrozen-cmd/EpochPact/releases

Feedback/support: https://discord.gg/q6aexZZSAf

For reports, include the EpochPact version, game/Steam build, Windows version, exact action/error and whether it happened during gameplay, app close or game exit. Don't post private saves or unredacted logs publicly.

## Guide outline

1. Supported game build and Windows dependencies.
2. Extract the complete player ZIP; keep the EXE configuration and _internal folder together.
3. Close the game, select Last Epoch.exe in Game setup, install the matching runtime, then launch offline.
4. Session settings apply after edits; save-changing actions require their own buttons.
5. Customize menus in Settings, summon columns in Summons and hidden stats in Character.
6. Update and remove only EpochPact-owned files; preserve other loaders, mods and saves.
7. Read the release's validation report and known limitations before reporting a problem.

This is a draft for the author to review and post. No Steam publication has been performed.
