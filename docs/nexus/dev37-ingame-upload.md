## Changelog

- EpochPact now runs entirely inside the game: press F6 for the full EpochPact window
  (all pages: General, Loot & Pickup, Crafting, Character, Skills & Trees, Equipment,
  Summons, Display & Camera, World, Inventory, Unique Atlas, Stash Assistant, Campaign,
  Monolith, Circle of Fortune, Factions, Settings). No desktop app, Python, WebView2 or
  MelonLoader needed.
- Damage window and recent pickups as in-game overlays that stay while the window is closed.
- Loot filter files: list, duplicate, export, import from XML or ZIP, backups.
- Auto pickup no longer stops after you pick up an item label by hand.

## Install (manual)

1. Close Last Epoch. Back up your offline saves.
2. Steam: right-click Last Epoch → Manage → Browse local files.
3. Copy version.dll from the ZIP next to Last Epoch.exe (replace an older EpochPact version.dll).
4. Start Last Epoch, play offline, load your character, press F6.

Uninstall: delete that version.dll. Saves and other mods stay.
