Source code and build steps
- Source for this exact build: https://github.com/falorfrozen-cmd/EpochPact/tree/d497721574e59a56a515a2fe48b81406438fbc83
- Build (Windows, MSVC x64): native\build.bat player
  This writes native\build\player\version.dll (the loader with the mod's core linked in) and native\build\player\EpochPact.Core.dll.
- App (Python environment from requirements-build-win64.lock): python -m tools.build_player --layout onedir --version 0.1.2-dev.36
- ZIP: python -m tools.package_player_folder --bundle dist/EpochPact --output dist/share
- The README section "Build and test" describes the same steps.

What is inside
- EpochPact/EpochPact.exe: the desktop app (PyInstaller folder build, no UPX, no obfuscation). On request it copies the game-side file into the Last Epoch folder and shows the settings.
- version.dll (in "Manual Installation" and in EpochPact/_internal/native/build/player): the game-side mod. In this release the mod's core is linked into this one DLL. It forwards the Windows version API to Windows and starts the mod only inside Last Epoch.exe; it does not load any other DLL from the game folder.
- EpochPact.Core.dll: the same core as a separate file, used only by the optional MelonLoader bridge.
- EpochPact.MelonBridge.dll: optional bridge for players who already use MelonLoader.
- A standard ZIP: no installer, no self-extracting archive, no nested archives, no password.
