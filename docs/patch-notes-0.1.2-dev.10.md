# EpochPact 0.1.2-dev.10

Crafting is now organized around three clear tasks:

- **Forge Settings** — preserve shards, runes and glyphs, adjust FP costs and
  choose game-default or custom glyph chances.
- **Materials** — stock your crafting stash to a chosen minimum with one
  confirmed action.
- **Custom Items** — select equipment, search templates and affixes, then review
  the result before creating it.

Affixes and extra effects use checkboxes instead of multi-select lists. Searches
and category/theme changes keep your selections. Selected choices can be removed
individually. Optional mixed effects sit in an advanced section, and invalid
recipes show a clear reason before any write.

The crafting header takes less vertical space. Advanced Forge sections remain
open after refreshes and actions. Material confirmation shows the character and
exact target quantity. Roll descriptions match how existing affixes are treated.

Live checks covered material preservation, zero FP cost, normal-default reset,
stocking all 525 material types and Exalted/Unique/Set custom recipes. Six
confirmed UI save actions created backups; this game session exited with code 0.
The rebuilt EXE passed 21 package/installer checks. See the
[validation report](crafting-ui-validation-2026-10-12.md) for test scope and limits.

Extract the complete ZIP. Keep EpochPact.exe.config and _internal beside the EXE.
Update with Last Epoch closed. Offline only; supported Steam game version
1.5.2.1, build 25816319. Mixed effects require EpochPact and workshop-recipes.txt.
