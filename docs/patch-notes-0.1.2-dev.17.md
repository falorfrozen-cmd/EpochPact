# EpochPact 0.1.2-dev.17

Player suggestions, second group.

## Recent pickups and the loot window

- The **Loot** page lists recent item, gold and amber pickups with rarity, who
  picked it up (you or Auto Pickup) and the **loot filter rule** that matched.
  "Rule N" is the same number the game shows with its Item rule numbering
  setting; the rule's name (or the game's description of it) is shown beside it.
- **Open loot window** opens a small window that stays on top of a windowed or
  borderless game: resizable, with an opacity slider and Gold/Materials filters.

## More things Auto Pickup can collect

- New pickup category **Memory Amber, Soul Embers and XP motes**. The game
  normally collects them only when you walk close; Auto Pickup and Pick up
  everything now can collect them like gold.

## Support report

- **Settings → Support report** creates a ZIP with your description, versions,
  setup state, recent EpochPact logs and an optional screenshot of the game
  window. Nothing is uploaded; the folder opens so you can attach it on Discord.
  Your Windows user name is masked.

## Updating

Close Last Epoch and EpochPact. Extract the **complete new ZIP**, open
`EpochPact/EpochPact.exe`, and select **Game setup → Reinstall / update mod**.
