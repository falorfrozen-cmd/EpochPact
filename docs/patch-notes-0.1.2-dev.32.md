# EpochPact 0.1.2-dev.32

Weaver's Will, your way: more Weaver's Will Uniques, more Weaver's Will on
them, faster upgrades, and the affixes you choose.

## General → Weaver's Will

Every Weaver's Will setting is in one place.

- **Weaver's Will multiplier** (×1–×10): a Weaver's Will Unique gets that much
  more Weaver's Will when the game rolls it, up to the game's maximum of 28: at
  ×2 a Unique that would get 10 gets 20. Works for drops, rewards and opened
  cocoons. Items you already have do not change.
- **Weaver's Will Unique share** (0–100 %): normally about 4 % of the Uniques
  that drop are Weaver's Will Uniques. Set the share you want; where no Weaver's
  Will Unique fits the item type or level, you get the usual Unique. The four
  special Weaver's Will Uniques that never drop at random still don't.
- **Weaver's Will upgrade speed** (×1–×10): when a kill near you upgrades an
  equipped Weaver's Will item, the upgrade happens this many times. Each upgrade
  adds an affix or raises one by a tier and uses 1 Weaver's Will, as usual.
- **Weaver's Will affixes**: choose the affixes you want. An upgrade then raises
  one of them when your item has one below T7, and a new affix is one of them
  when one fits the item. When none can be raised or added, the game chooses as
  usual. Select **Refresh** to load the affix names, then **Apply selection**.

## Loot & Pickup → Quality rules

- **Minimum Weaver's Will** (0–28): Quality mode now also picks up Weaver's
  Will Uniques with at least this much Weaver's Will. Before, they were never
  picked up with Minimum Unique LP above 0, because they have no Legendary
  Potential.

## Translations

- The new texts are translated into Türkçe and Русский (the Russian interface
  uses the game's own «Воля Ткача»).

## Updating

With 0.1.2-dev.22 or later: **New version · What's new → Install update** in
the app. From an older version: close Last Epoch and EpochPact, extract the
**complete new ZIP**, open `EpochPact/EpochPact.exe`, and select **Game setup →
Reinstall / update mod**. The new settings need the updated mod: Install update
reinstalls it once the game is closed.
